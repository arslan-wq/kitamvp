  ☑️ Gibt es die 5 Meal-Type-Optionen beim ExtraDay buchen?
     ✓ FULL_DAY (Ganztägig)
     ✓ MORNING_WITH_MEAL (Vormittag mit Essen)
     ✓ MORNING_NO_MEAL (Vormittag ohne Essen)
     ✓ AFTERNOON_WITH_MEAL (Nachmittag mit Essen)
     ✓ AFTERNOON_NO_MEAL (Nachmittag ohne Essen)

  ☑️ Funktioniert die Child-Location Zuordnung?
     - Kind wird zu Location zugeordnet
     - Location zeigt das Kind in ihrer Liste
     - Betreuer sieht nur Kinder seiner Location

  ☑️ Funktioniert das Email-System?
     - Parent Invitation Email wird versendet
     - Email kommt von: noreply@kitaluna-app.ch
     - Email enthält temporäres Passwort

  ☑️ Berechtigungen funktionieren?
     - Eltern: Sehen NUR ihre eigenen Kinder
     - Betreuer: Sehen NUR ihre Location-Kinder
     - Admin/Leiter: Sehen ALLE Kinder
     - Nur Admin/Leiter können Locations erstellen

  "Webseite ist nicht erreichbar"
  → Server neustarten: npm run dev

  "Passwort falsch"
  → Kopiere exakt aus TEST_USERS.md (case-sensitive!)

  "ExtraDay Type zeigt nicht alle Optionen"
  → Browser-Cache löschen (Strg+Shift+Entf)

  "Email kommt nicht"
  → Überprüfe Resend.com ob Domain verified ist
  → Logs anschauen: tail -50 /tmp/kita-dev.log

  "Betreuer sieht Kinder von anderer Location"
  → Betreuer muss locationId zugewiesen haben
